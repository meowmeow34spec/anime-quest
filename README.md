# ADHD를 위한 애니 보기 퀘스트

애니를 한 화씩 체크하면서 XP, 레벨, 연속 시청, 배지를 모으는 개인용 페이지예요.
한 파일(`index.html`)이고 인터넷 없이도 열려요. 깜빡임이나 큰 애니메이션은 없어요.

## 여는 법
`index.html`을 더블클릭하면 브라우저에서 열려요. `images/` 폴더가 같은 곳에 있어야 그림이 보여요.

## 작품 추가하는 법
**A. 페이지에서 (제일 쉬움)**
「작품 추가」 버튼 → 제목, 총 화수(몰라도 됨), 이미지(파일 올리기 또는 이미지 주소) → 저장.
추가한 작품은 카드의 「편집」에서 고치거나 지울 수 있어요. 기본 작품도 총 화수, 이미지를 바꾸거나 숨길 수 있어요.
(이미지 주소를 넣으면 그때만 그 사이트에서 그림을 불러와요. 기본 페이지는 외부 요청이 없어요.)

**B. 파일을 직접 고쳐서 (기본 목록에 넣고 싶을 때)**
1. 그림을 `images/`에 넣어요 (webp나 jpg, 가로 800px 정도면 충분해요).
2. `data/anime.json`에 한 줄 추가해요: `id`, `title`, `totalEpisodes`(모르면 `null`), `image`(`images/파일이름`), `source`(출처 링크).
3. `python3 build/build.py`를 돌리면 `index.html` 안의 `const ANIME = [...]`가 다시 만들어져요.
   빌드 없이 `index.html` 맨 아래 스크립트의 `const ANIME` 부분을 직접 고쳐도 돼요. (다음 빌드 때 json 내용으로 덮어써져요.)
   참고: 파일로 열면(file://) 브라우저가 `data/anime.json`을 읽지 못해서, 데이터를 스크립트 안에 넣어 둔 거예요.

## 진행 기록은 어디에?
이 브라우저의 localStorage(`aq-v1`, 테마는 `aq-theme`)에 저장돼요.
다른 기기나 다른 브라우저와는 동기화되지 않아요. 브라우저 데이터를 지우면 기록도 지워져요.
페이지 맨 아래 「데이터 초기화」로 직접 지울 수도 있어요 (한 번 더 확인해요).
